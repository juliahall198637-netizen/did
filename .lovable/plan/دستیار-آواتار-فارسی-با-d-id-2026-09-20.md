# دستیار آواتار فارسی با D-ID

یک صفحه تمام‌صفحه که فقط آواتار D-ID را نشان می‌دهد و کاربر با آن حرف می‌زند. تنظیمات و کلیدها از یک پنل مدیریت مخفی کنترل می‌شوند.

## صفحه اصلی

- پس‌زمینه تیره و مینیمال، آواتار در مرکز صفحه، تمام‌صفحه.
- هیچ چت‌باکس، منو، فرم یا دکمه ارسالی وجود ندارد.
- ایجنت D-ID با تنظیمات ذخیره‌شده بارگذاری می‌شود؛ خودش صدای کاربر را می‌شنود، پاسخ می‌سازد و با حرکت لب طبیعی جواب می‌دهد و دوباره آماده شنیدن می‌شود.
- زبان ایجنت روی فارسی (fa-IR) تنظیم می‌شود.
- حالت‌های کوچک و بی‌صدا: «در حال بارگذاری»، «اجازه میکروفون لازم است»، «هنوز تنظیم نشده» (فقط وقتی مدیر هنوز اطلاعات را وارد نکرده).
- یک آیکون چرخ‌دنده بسیار کم‌رنگ در گوشه پایین صفحه.

## پنل مدیریت

- کلیک روی چرخ‌دنده → صفحه ورود مدیر (ایمیل و رمز).
- فقط حساب‌هایی که نقش مدیر دارند پنل را می‌بینند؛ بقیه پیام «دسترسی ندارید» می‌گیرند.
- بخش‌های پنل:
  - اطلاعات ایجنت D-ID: Client Key، Agent ID، آدرس اسکریپت Embed.
  - مقادیر نمایش: Mode، Name، Monitor، Light Mode، Orientation، Position، Open Mode.
  - کلید API سرویس D-ID برای تست اتصال.
  - دکمه «تست اتصال» و «تست بارگذاری ایجنت» با نمایش وضعیت (موفق/ناموفق و پیام خطا).
  - ذخیره تنظیمات؛ تغییر ایجنت بدون تغییر کد.
- کلید API فقط روی سرور نگه‌داری می‌شود و هرگز به صفحه عمومی فرستاده نمی‌شود. صفحه عمومی تنها Client Key و Agent ID (که به‌صورت طراحی عمومی هستند) و مقادیر ظاهری را می‌گیرد.

## زیرساخت

- Lovable Cloud برای ورود مدیر و ذخیره تنظیمات فعال می‌شود.
- جدول تنظیمات (یک رکورد) + جدول نقش‌ها برای مدیرها.
- اولین حساب ساخته‌شده به‌صورت دستی مدیر می‌شود؛ روش ساخت آن را بعد از پیاده‌سازی توضیح می‌دهم.

## جزئیات فنی

- مسیرها: `/` (آواتار تمام‌صفحه)، `/admin/login`، `/admin` (محافظت‌شده).
- جدول `did_settings`: client_key, agent_id, embed_script_url, mode, name, monitor, light_mode, orientation, position, open_mode, updated_at. جدول `user_roles` + تابع `has_role` برای نقش مدیر. RLS: خواندن مقادیر غیرحساس برای همه، نوشتن فقط برای مدیر.
- کلید API با ابزار امن پروژه به‌عنوان secret ذخیره می‌شود؛ تست اتصال با یک server function انجام می‌شود که به `https://api.d-id.com/credits` درخواست می‌زند و فقط وضعیت را برمی‌گرداند.
- اسکریپت Embed ایجنت به‌صورت پویا با `data-*` تزریق می‌شود و در تغییر تنظیمات دوباره mount می‌شود.
- شنیدن گفتار فارسی، تولید پاسخ و صدا همگی توسط خود ایجنت D-ID انجام می‌شود (بدون لایه تشخیص گفتار جداگانه).

## محدودیت‌ها

- کیفیت تشخیص گفتار فارسی به تنظیمات ایجنت در داشبورد D-ID وابسته است (انتخاب زبان، مدل و Presenter آنجا انجام می‌شود).
- بدون Client Key و Agent ID معتبر، صفحه اصلی حالت «تنظیم نشده» را نشان می‌دهد.
